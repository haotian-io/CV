\entrytitle
  {CETI: Evidence-Constrained Collaborative Task Interpretation}
  {Mar. 2026 -- Present}

\entryrole{
  First Author
  \textbar{}
  Collaboration with ZGC Lab (PKU) and Waseda University
}

\begin{cvitems}
  \item Identified a cognitive gap--intent gap in repository-level
  AI coding and proposed CETI, which generates atomic
  task-constraint \textbf{Records} bound to repository evidence,
  enabling developers to inspect and revise an agent's interpretation
  \emph{before} a patch is generated.

  \item Designed a four-stage pipeline (repository inspection,
  source binding, developer review, coding handoff) and a
  three-condition human study comparing FreeChat and one-/two-cycle
  Records on objective comprehension, patch correctness, and
  constraint satisfaction over ten FEA-Bench cases.
\end{cvitems}
